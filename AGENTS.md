# Правила сопровождения исследования

1. Все научные документы, описания, комментарии к изменениям, сообщения о задачах и запросах на объединение изменений писать на русском языке. Для технических идентификаторов, формул и общепринятых названий пакетов допускается латиница.
2. Не выдавать иллюстративную калибровку за оценку параметров по данным.
3. Разделять аналитические утверждения, результаты численной проверки и ещё не проверенные гипотезы.
4. Сохранять одинаковые предпочтения, технологию, структуру рынка и денежную политику при сравнении режимов цен. Для гибких цен полагать `mc_hat = 0`, не подставлять `theta = 0` в формулу наклона кривой Филлипса.
5. При изменении уравнений обновлять математическое описание и тесты. Перед фиксацией изменения запускать `python -m unittest discover -s tests -v`.
6. Сохранять рисунки по одному в каждом SVG-файле, обеспечивать математический шрифт для обозначений и русские подписи.
7. Не утверждать, что удалённые проверки выполнены, если их результат не был получен.
