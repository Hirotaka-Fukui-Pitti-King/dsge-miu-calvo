# Правила сопровождения исследования

1. Все научные документы, описания, комментарии к изменениям, сообщения о задачах и запросах на объединение изменений писать на русском языке. Для технических идентификаторов, формул и общепринятых названий пакетов допускается латиница.
2. Не выдавать иллюстративную калибровку за оценку параметров по данным.
3. Разделять аналитические утверждения, результаты численной проверки и ещё не проверенные гипотезы.
4. Сохранять одинаковые предпочтения, технологию, структуру рынка и денежную политику при сравнении режимов цен. Для гибких цен полагать `mc_hat = 0`, не подставлять `theta = 0` в формулу наклона кривой Филлипса.
5. При изменении уравнений обновлять математическое описание и тесты. Перед фиксацией изменения запускать `python -m unittest discover -s tests -v`.
6. Сохранять рисунки по одному в каждом SVG-файле, обеспечивать математический шрифт для обозначений и русские подписи.
7. Не утверждать, что удалённые проверки выполнены, если их результат не был получен.

8. При правках линейной динамики сравнивать Якобианы исходных условий и независимое QZ-решение; не считать успех проверки собственных значений достаточным доказательством.
9. Документировать статус удалённого CI отдельно от локальных тестов и не представлять решение первого порядка как нелинейное стохастическое равновесие.

10. Для второго этапа различать вычисленные ковариационные составляющие по политике первого порядка и истинные премии, вытекающие из уравнений Эйлера второго порядка. Не публиковать CEV без полного расчёта второго порядка.
11. Англоязычную статью, её таблицы и рисунки вести на английском языке; правила разработки и научные журналы вести на русском.

12. Для приближения второго порядка использовать полные рекурсии F и G, не подменять их линейной кривой Филлипса. Подтверждать независимой квадратурой исходных условий.
13. Для расчёта премий и CEV различать стандартные отклонения шоков и амплитуду разового IRF; не объявлять надёжными результаты при больших волатильностях, если ошибка Эйлера сопоставима с премией.
14. Наличие расчёта второго порядка при общем рынке капитала не означает решение экономики с капиталом отдельных фирм. Сохранять этот статус явно в исследовательской документации и английской статье.
