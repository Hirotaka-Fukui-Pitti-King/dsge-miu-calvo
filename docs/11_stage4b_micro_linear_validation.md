# Этап 4-B: микрооснование первого порядка и граница нерешённого нелинейного равновесия

**Статус: частично завершено.** Восстановлено независимое симметричное нелинейное стационарное равновесие, исправлено уравнение капитала в агрегированной системе, независимо проверены относительные условия Euler и Кальво и переход первых двух моментов распределения. Полное нелинейное переходное общее равновесие для ненулевых шоков НЕ решено.

## 1. Ошибка исходного агрегированного Euler

Пусть

\[
\Psi(I,K)=\frac{\phi_I}{2}K(I/K-\delta)^2,\qquad
q=1+\Psi_I.
\]

Точная производная по установленному капиталу:

\[
\Psi_K=\frac{\phi_I}{2}[\delta^2-(I/K)^2].
\]

Из условия огибающей следует

\[
V_{K,t}=r^k_t-\Psi_{K,t}+(1-\delta)q_t.
\]

Поскольку в первом порядке \(-\widetilde\Psi_{K,t}=\delta\widetilde q_t\), правильное линейное условие:

\[
\widetilde q_t+\sigma(E_t\widehat c_{t+1}-\widehat c_t)
-\beta\bar r^k E_t\widehat r^k_{t+1}
-\beta E_t\widetilde q_{t+1}=0.
\]

Ранее вместо последнего коэффициента \(\beta\) ошибочно использовался \(\beta(1-\delta)\). Изменён \`src/firm_specific_capital.py\`, обновлены IRF и тесты.

Максимальная нормированная невязка \(\approx1.55\times10^{-15}\). Условия оптимального пересмотра цены и инвестирования выполнены; \(P_j/P=1\), \(I=\delta K\), а масса фирм сосредоточена в симметричном состоянии. Это проверка **стационара**, не переходного решения.

## 3. Независимая микротеория первого порядка

Для относительного капитала \(h_j=\widehat k_j-\widehat K\) и выбранной относительной цены \(p_j=\log(P_j/P)\), обозначим \(\lambda,\tau,\psi\) коэффициенты

\[
h_{j,t+1}=\lambda h_{j,t}-\tau p_{j,t},\qquad
p_{j,t}^{R}=\frac{\theta}{1-\theta}\pi_t-\psi h_{j,t}.
\]

Эти коэффициенты вычисляются из трёх независимых уравнений: двух коэффициентов индивидуального Euler капитала и долгосрочного условия оптимальной цены при отсутствии повторного пересмотра с весами \((\beta\theta)^s\). Квартет Woodford не использовался как условие в независимом решателе.

Получено:

- \(\lambda=0.929049708664447\);
- \(\tau=0.174765965495934\);
- \(\psi=0.109060241481429\);
- \(\kappa_{\mathrm{specific}}=0.022893947503573\).

Остаток трёх независимых уравнений меньше \(1.5\times10^{-15}\). Для обоих шоков FOC оптимальной цены по 200 кварталам и относительное условие инвестиций имеют остатки порядка \(10^{-16}\). Эти результаты подтверждают прежний наклон NKPC, **но не прежние агрегатные IRF**.

## 5. Совместное распределение на первом порядке

Для \((h_{j,t},p^-_{j,t})\) переход каждой из двух ветвей Кальво является аффинным. Их весовая смесь \(\theta\) и \(1-\theta\) переносит точно средний вектор и ковариационную матрицу **линейной системы**, без сеточной проекции и без перечисления экспоненциально растущего числа истории фирм.

Для шоков по 200 кварталам наибольшая ошибка первой производной CES-индекса меньше \(2.2\times10^{-18}\), ошибка среднего относительного капитала меньше \(2.2\times10^{-19}\). Максимальная абсолютная ковариация относительных капитала и цены, рассчитанная из линейных политик: \(1.5367\times10^{-5}\) (технологический шок) и \(5.5140\times10^{-6}\) (денежный шок). Это вспомогательные моменты локальной политики, не второпорядочное равновесие.

**Принципиальное ограничение:** при ненулевом шоке первый порядок выполняет лишь линейное тождество

\[
(1-\varepsilon)\int p_{j,t}\,dj=0,
\]

но не точное нелинейное тождество

\[
\int\exp[(1-\varepsilon)p_{j,t}]\,dj=1.
\]

Оценка исключительно квадратичного вклада некомпенсированной дисперсии в индекс CES достигает порядка \(1.6\times10^{-4}\) для денежной и \(3.8\times10^{-4}\) для технологической инновации. Эти поправки первого порядка **не содержат** необходимых сдвигов среднего второго порядка, поэтому полный нелинейный остаток не может считаться малым по данной проверке.
