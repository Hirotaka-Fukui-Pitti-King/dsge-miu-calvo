# Проверка вычислений и ограничения достоверности

## Проверки, выполненные локально

На иллюстративной калибровке проверены:

1. Согласованность стационарного ограничения ресурсов и накопления капитала.
2. Равенство арендных ставок предельным продуктам с учётом монополистической надбавки.
3. Условие предложения труда и оба уравнения Эйлера в стационаре.
4. Стационарный спрос на реальные денежные остатки.
5. Число устойчивых и неустойчивых собственных значений, а также ранг устойчивого подпространства.
6. Инвариантность вычисленного устойчивого подпространства относительно матрицы динамики.
7. Нейтральность денежного шока для реальных переменных при гибких ценах.
8. Ненулевой реальный отклик на денежный шок при Calvo Pricing.

Запуск: `python -m unittest discover -s tests -v` и `python -m src.experiment`.

## Численные корни

Для Calvo Pricing (`θ=0,75`) собственные значения:

$$0{,}800000,\quad0{,}900000,\quad0{,}945482,\quad1{,}068381,\quad1{,}663903,\quad2{,}243578.$$

Имеются три корня вне единичного круга при трёх независимых jump variables; выполнена проверка ранга соответствующих собственных векторов.

Для гибких цен (`θ=0`) собственные значения:

$$0{,}800000,\quad0{,}900000,\quad0{,}951375,\quad1{,}072633,\quad1{,}500000.$$

Имеются два корня вне единичного круга при двух jump variables; соответствующий ранг также полный.

Таким образом, **обе линеаризованные системы локально определены только для указанной калибровки**. Из этого не следует глобальная единственность, корректность нелинейного равновесия или общая теорема об определённости.

## Не выполнено

- Независимая проверка аналитических производных нелинейной модели автоматическим дифференцированием.
- Реализация полной нелинейной стохастической системы с государственным бюджетом.
- Сопоставление с независимой реализацией в Dynare или другом решателе рациональных ожиданий.
- Вывод и вычисление благосостояния второго порядка, а также риск-премий.
- Успешный запуск удалённого процесса непрерывной интеграции: пока не подтверждён, поскольку код ещё не отправлен в удалённый репозиторий.

Это перечень ограничений текущей версии, а не результаты несуществующих проверок.
