# Результаты независимой проверки — этап 1

## Вывод

Для **зафиксированной иллюстративной калибровки** проверенная линейная модель согласуется с независимо дифференцированными нелинейными условиями домохозяйства и фирм (с учётом исчезновения ценовой дисперсии в первом порядке). Независимое QZ-решение совпадает с исходным решением на собственных векторах. Обе версии модели удовлетворяют условию Бланшара — Кана и условию ранга. Это утверждение о **локальном линейном решении**, а не о полной нелинейной стохастической экономике.

## Воспроизведение

```powershell
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m src.audit
python -m src.experiment
```

Проверка выполнена локально с Python 3.13.5, NumPy 2.3.5, SciPy 1.17.0 и Matplotlib 3.10.8. Автоматически выполнено **19 проверок из 19**; первоначальный тест с недостаточно длинным горизонтом сходимости (250 периодов) выявил не ошибку равновесия, а слишком строгий критерий для медленно затухающего корня. Горизонт теста увеличен до 500 периодов. Это изменение зафиксировано, а тест повторно выполнен.

Наибольший абсолютный остаток проверенных **нелинейных условий в стационаре** равен `1.11×10⁻¹⁶`. Проверены бюджет домохозяйства при нулевой эмиссии в стационаре, условие равенства дивидендов чистой прибыли, ресурсы, накопление капитала, условия спроса на факторы, труд, два уравнения Эйлера, спрос на деньги, рекурсии пересмотра цены и индекс цен. Совпадение стационаров при `θ=0` и `θ=0.75` следует из одинаковой монопольной надбавки.

Собственные значения, полученные независимо методом QZ:

- Гибкие цены: `0.800000, 0.900000, 0.951375, 1.072633, 1.500000`.
- Цены по Кальво: `0.800000, 0.900000, 0.945482, 1.068381, 1.663903, 2.243578`.

Коэффициент NKPC, восстановленный из независимых производных двух нелинейных рекурсий цены и индекса цен: `κₚ=0.0858333333`.

## Импульсные отклики

Для технологической инновации `0.01` логарифмической единицы и денежной инновации `0.0025` логарифмической единицы валовой номинальной ставки рассчитаны отклики за периоды `0–40` в обоих режимах. Политика реагирует на **отклонение выпуска от стационарного уровня**, а не на гибкоценовой разрыв выпуска.

| Величина в периоде 0 | Технология, гибкие цены | Технология, Кальво | Денежная политика, гибкие цены | Денежная политика, Кальво |
|---|---:|---:|---:|---:|
| Выпуск, логарифмическое отклонение | `0.01337225` | `0.01249910` | `0` | `-0.00431472` |
| Потребление | `0.00330584` | `0.00349228` | `0` | `0.00017552` |
| Инвестиции | `0.05470091` | `0.04947752` | `0` | `-0.02274988` |
| Труд | `0.00503320` | `0.00373000` | `0` | `-0.00643988` |
| Инфляция | `-0.00237619` | `-0.00229325` | `-0.00357143` | `-0.00320295` |

При гибких ценах денежный шок не изменяет реальные решения, хотя номинальная инфляция и ставка изменяются. При ценах по Кальво положительная инновация правила снижает выпуск приблизительно на `0.431 %`, а инвестиции — на `2.275 %` в первом периоде. Первоначально потребление при этом **немного возрастает** (`0.0176 %`): этот знак получен из модели, не навязан коду и связан с перераспределением ресурсов при отсутствии издержек корректировки инвестиций. Реализованная номинальная ставка в периоде 0 может снижаться из-за эндогенного отклика правила на инфляцию и выпуск; инновация правила не равна суммарному изменению ставки.

Максимальное расхождение IRF двух решений на 41 периоде не превышает `7×10⁻¹¹` логарифмической единицы. Линейные остатки исходных условий Эйлера, закона капитала и остальных переходных уравнений остаются ниже `10⁻¹⁰`. Нелинейные остатки на ненулевых IRF не обязаны обращаться в ноль: они имеют второй порядок по размеру шока. Это дополнительно проверено тестом масштабирования.

## Границы доказанного

1. Якобианы исходных FOC и ресурсных ограничений вычислены независимо центральной разностью. Уравнение цены Кальво сначала получено из независимых производных точных рекурсий, а затем использовано в сокращённой системе NKPC.
2. Денежно-фискальный блок в целом задан в стационаре, но динамическая **нелинейная** система номинальных обязательств и уровня цен отдельно не решалась.
3. Влияние ценовой дисперсии второго порядка, welfare и риск-премии не вычислялись. Дисперсия равна нулю лишь **в первом порядке** около нулевой стационарной инфляции.
4. Известные условия отсутствия схемы Понци и трансверсальности требуют указания допустимых портфелей и в полной стохастической задаче не подтверждены одной только BK-проверкой.
5. QZ-проверка относится к приведённому невырожденному переходному оператору, а не к произвольному сингулярному обобщённому пучку.
6. Для параметров, отличающихся от демонстрационных, определённость не доказана. Конкретная проверка устойчивости к иным калибровкам не является результатом данного этапа.
